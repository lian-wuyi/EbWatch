## 📖 产品介绍

**屏幕守卫（EbWatch）** 是一款面向企业的电脑使用管理与屏幕记录审计软件，旨在帮助企业了解授权管理设备的使用情况，提高日常管理效率，并为企业内部安全事件调查提供辅助记录。

通过屏幕截图记录、实时状态查看、历史记录查询及后台统计分析等功能，管理人员可以更方便地回顾设备使用情况，了解相关操作过程，减少因缺乏记录而造成的调查困难。

适用于有合法设备管理和信息安全审计需求的企业，例如制造企业、设计公司、办公团队及 IT 运维部门。

## ✨ 主要功能

### 1. 屏幕截图记录

对已纳入管理且完成必要告知和授权的 Windows 电脑，按照配置的时间间隔记录屏幕画面，便于后续查询和回顾。

### 2. 实时设备管理

通过集中管理界面查看已接入的设备及相关状态，帮助管理员了解设备运行和使用情况。

### 3. 历史截图查询

根据设备和时间范围查询历史屏幕记录，便于回顾特定时间段的工作过程。

### 4. 后台统计分析

通过管理后台查看设备使用记录及相关统计信息，为企业内部管理提供参考。

### 5. 企业集中管理

统一管理已授权接入的企业电脑，减少逐台查看和维护的操作成本。

### 6. 安全事件辅助调查

当企业发生资料泄露疑虑或其他内部安全事件时，可结合现有屏幕记录辅助调查。

**注意：** 屏幕记录只能作为辅助信息，不能单独证明员工存在违规行为，也不保证能够完整还原所有操作。
